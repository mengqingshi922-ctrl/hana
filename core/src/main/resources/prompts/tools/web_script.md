Run a JavaScript program against the current web page to do repetitive multi-step work in one call: read many list items, page through results, fill several fields. Not for a single action: use web_tap/web_type_text for that. code is the body of an async function; return a JSON-serialisable value. The script has no DOM: document, window, location, fetch and every other browser global are undefined; only plain JavaScript (Math, JSON, Array, …) and `hana` are there, and everything hana returns is plain data (always await): hana.snapshot() → {snapshotId, elements:[{ref, role, name, center}]}; hana.read({maxChars, offset}) → page text chunk {text, nextOffset}; hana.queryAll(cssSelector, {fields: ['text','attrs','value','box'], limit, maxChars}) → {items:[{tag, text, attrs, value, box}], total}; hana.query(cssSelector, opts) → first item or null (fields ['count'] → number); hana.text(cssSelector) → visible text (password-like values read as ***); hana.tap(ref); hana.type(ref, text, {enter}); hana.scroll('down'|'up'|'left'|'right', {amount}); hana.navigate(url); hana.wait(ms) or hana.wait({text, timeoutMs}) → true/false; hana.log(...). tap/type use refs from the latest hana.snapshot() in the script. Every action runs through the same execution and recording path as a normal call, including send, post, order, delete and pay. A failed hana call throws an Error whose message starts with the error code. Limits: {{max_actions}} actions, {{max_reads}} reads, {{max_seconds}} s. A navigation that loads a new page ends the script (endedBy=navigation). Returns result (JSON), logs, and actions with each outcome. Call web_observe before acting after it: the page may have changed.
